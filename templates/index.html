HONEST BY DESIGN

Feedback you can understand.

Interview scores use a transparent text rubric—not emotion detection or personality judgments. AI question generation and voice tools are available when the service is configured; curated questions and text practice remain available as a fallback.

GOOD TO KNOW

Frequently asked questions

Do I need an AI API key to practice?

No. Curated questions and rubric-based text feedback work without an AI key. AI question generation, Copilot, and generated voice require the service to be configured by the site operator.

How are mock interview answers evaluated?

The current mock interview uses a transparent text rubric for completeness, clarity, relevance, evidence, and structure. It does not claim to measure confidence, emotion, or personality.

Can I upload a resume or execute code here?

Resume tools currently analyze text you paste into the page; file uploads are not enabled. Coding Arena reviews your approach without running submitted code on the application server.
